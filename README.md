# MRI 检查模拟器（MRI Exam Simulator）

一个纯前端的 Web 应用，帮助患者提前熟悉 MRI（磁共振）检查的流程、阶段提示和机器噪音，缓解检查前的焦虑和恐惧。

## 🎯 项目地址
https://xhurongna.github.io/mri-simulator/

## ✨ 功能特点
- 支持 9 种 MRI 检查部位（头部、心脏、乳腺、腹部、盆腔、颈椎、腰椎、全脊柱、通用）
- 7 个阶段流程模拟，含文字说明和真实机器声音
- 预录人声语音播报 + 文字字幕
- 语音播报开关 / 扫描音效开关
- 手机端适配，体验流畅

## 🔊 音频来源
- MRI 扫描声音由 solidphase 录制，遵循 CC BY 4.0 许可证
- 人声语音由 Mac 系统 TTS 生成，仅供公益体验使用

## 🛠️ 技术栈
- 纯前端：HTML + CSS + JavaScript（ES6+）
- 部署平台：GitHub Pages
- 许可证：AGPL-3.0

## 📱 使用场景
- 预约 MRI 后，提前了解检查流程
- 候诊时缓解紧张情绪
- 帮助老年患者或首次检查者建立心理预期
